# Law Firm Landing Page

Responsive landing page for a debt collection law firm, built from scratch to my own design.

## Features

- Hero slider
- Services and advantages sections
- News section
- Contact form and consultation modal
- Responsive mobile layout

## Tech stack

HTML5, CSS3, JavaScript, jQuery, Slick, Fancybox

## Getting started

Open `src/main/webapp/index.html` in a browser.
